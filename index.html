Four distinct visual directions for the EasyBridge website. Open each template to explore the full site: navigate between pages using the top nav — no scrolling between sections.

What's been fixed across all templates

Single-page app navigation — nav links switch between pages instantly, no scroll-to-section behaviour
Services and Pricing are no longer duplicated — T1/T3/T4 have Services; T2 (Edge) has Pricing with FAQs instead
Audience filter fixed — "For Learners" now shows only Cloud Tools Training; "For Professionals" shows both Cloud Tools and AI Tools
All 3 business service cards (Implementation · Recruitment · FP&A) are visible at once in a compact 3-column layout without scrolling
About page now combines "About EasyBridge" + "Why EasyBridge" values in one place
Who We Serve page now combines audience tabs + Client Stories / Testimonials in one place
Email-only CTA section removed — Contact page has a single full form (name, email, WhatsApp, role, service interest, message)
Location removed from contact section
All service buttons now read "Enquire Now"
Footer position fixed — no longer overlaps content. Removed fixed-height viewport constraint so footer flows naturally after page content
Footer colour now matches each template's brand: T1 & T4 use dark teal (#084D4D), T2 (Edge) uses the dark surface with a teal top border, T3 (Flow) uses the primary teal (#0D6E6E) matching its gradient hero
